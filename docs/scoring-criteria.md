## 評価項目と採点基準（各項目5点満点・合計35点満点）

### 01｜硬さ（5点満点）

**評価の視点：**  
ユーザーの体型・寝姿勢の多様性に対応できる硬さ設計かどうか。部位ごとに硬さが変わるゾーン設計の有無も加点対象。

| 点数 | 基準 |
|------|------|
| 5.0 | 部位別ゾーン設計あり（腰部・肩部で硬さが明確に異なる）または複数硬さバリエーションから選べる |
| 4.5 | 全体的に硬さバランスが優れており幅広い体型・寝姿勢に対応できる設計 |
| 4.0 | 硬さは適切だが、特定の寝姿勢（仰向け・横向き）にやや偏った設計 |
| 3.5 | 一般的な硬さだが、体重が重い方や軽い方には対応しにくい |
| 3.0以下 | 硬さのバリエーションがなく、体型の偏りが大きい |

**各商品の採点根拠：**
- **LIMNE（リムネ）4.0点**：やわらかめ志向の独自設計（25N〜140N）。幅広い体型に対応できるが、体重が重い方（80kg以上）は沈み込みすぎる口コミも存在。ゾーン設計ではなくレイヤー別の硬度差で対応。
- **雲のやすらぎプレミアム モデル3R 5.0点**：腰部のみ超高反発260Nを採用した5層ゾーン設計。腰・肩・足それぞれに異なる素材を配置しており、部位別硬さ設計として最高水準。
- **NELLマットレス 4.0点**：センターハード設計（腰部中央を硬めに設計）。ポケットコイルの独立動作により部位別対応はできているが、硬さバリエーションの選択肢はない。

### 02｜体圧分散（5点満点）

**評価の視点：**  
就寝中に体重が特定の部位（腰・肩・かかと）に集中せず、全体に均等に分散されるかどうか。血行障害・痛みの発生しにくさに直結する。

| 点数 | 基準 |
|------|------|
| 5.0 | 独自設計または部位別構造で体圧分散が最高水準。腰・肩の圧力集中がほぼない |
| 4.5 | 体圧分散は優秀。特定部位への集中を軽減できている |
| 4.0 | 標準的な体圧分散。長時間同一姿勢では一部に圧力がかかりやすい |
| 3.5 | 体圧分散がやや不足。特定の寝姿勢では痛みが出やすい可能性あり |
| 3.0以下 | 体圧分散が不十分。腰や肩に圧力が集中しやすい設計 |

**各商品の採点根拠：**
- **LIMNE（リムネ）5.0点**：トップ層の独自素材「Souffair（スフエアー）」25Nが体圧を面全体に広げ、中間層の格子状切り込み構造（120N）が肩・お尻・ふくらはぎの3部位ごとに沈み込みを制御。2つの構造が組み合わさることで体圧分散性能が最高水準に達する。
- **雲のやすらぎプレミアム モデル3R 4.5点**：5層ウレタンのゾーン設計で部位別に体圧を分散。腰部集中設計のため腰への対応は最高だが、全身の均一な体圧分散という観点ではLIMNEに次ぐ評価。
- **NELLマットレス 4.5点**：ポケットコイルが独立して動くため、体の凹凸に追従して個別に体圧を受け止める。コイル構造の体圧分散は優秀だが、ウレタン素材と比較すると点での支持になりやすい側面もある。

### 03｜寝心地（5点満点）

**評価の視点：**  
実際に寝た際の快適さ・フィット感・肌触り。購入者の口コミ満足度も重視する。単純な柔らかさではなく、起床時の疲労感のなさも評価に含む。

| 点数 | 基準 |
|------|------|
| 5.0 | 購入者の満足度が非常に高く、「他にはない寝心地」等の評価が多数。起床時の疲労感が明確に改善される |
| 4.5 | 満足度が高く、素材・構造から快適性が裏付けられる |
| 4.0 | 一般的に良好な寝心地。ただし体型・好みで合わない人も一定数いる |
| 3.5 | 寝心地は普通〜良好だが、差別化ポイントが弱い |
| 3.0以下 | 寝心地に関する否定的な口コミが目立つ |

**各商品の採点根拠：**
- **LIMNE（リムネ）5.0点**：「高反発でも低反発でもない」独自の寝心地に対し、「今まで合うマットレスがなかったが解決した」という口コミが多数。Amazonレビュー4.5以上（参照時点）。腰痛・肩こり・不眠の改善報告が特に多い。
- **雲のやすらぎプレミアム モデル3R 5.0点**：23cmの極厚設計により底付き感がゼロで、体重が重めの方にも対応。日本製素材の安心感と合わせて高い満足度。ただし体重が軽い方には硬めに感じるケースも。
- **NELLマットレス 4.0点**：ポケットコイルの弾力ある寝心地は好評だが、コイル特有の音（経年）や振動伝達が気になる口コミも存在。横向き寝には特に向くが、仰向け派からは普通評価が多い。

### 04｜寝返りやすさ（5点満点）

**評価の視点：**  
マットレスが体を適切に押し返し、無理なく寝返りを打てるかどうか。寝返りの妨げは血行不良・腰痛・朝の疲労感に直結するため重要指標。

| 点数 | 基準 |
|------|------|
| 5.0 | 高反発または同等の反発力を持ち、寝返りに余分な体力を使わない。寝返り補助設計あり |
| 4.5 | 寝返りしやすい反発力。ほとんどのユーザーが自然に寝返りを打てる |
| 4.0 | 標準的な反発力。やや意識して動く必要があるケースも |
| 3.5 | 柔らかめの素材で寝返りに若干の抵抗感あり |
| 3.0以下 | 沈み込みが強く、寝返りに体力を要する |

**各商品の採点根拠：**
- **LIMNE（リムネ）4.5点**：ミドル層（120N）の格子状切り込み構造が寝返りをアシスト。低反発ほど沈み込まず、高反発ほど跳ね返らない独自の反発力で自然な寝返りをサポート。ただし純粋な高反発素材と比較すると反発スピードはやや穏やか。
- **雲のやすらぎプレミアム モデル3R 4.0点**：腰部260Nの超高反発で腰まわりの寝返りサポートは強力。ただし23cmの極厚＋5層構造のため全体的な重量感があり、寝返りの動き出しがやや重く感じる場合もある。
- **NELLマットレス 5.0点**：ポケットコイル（2,043個以上 / シングル）の高い反発力とセンターハード設計の組み合わせで、3商品中最も寝返りがしやすい。コイルのバネ特性が体を素早く押し返すため、寝返り回数の多い人に特に向く。

### 05｜価格（コスパ）（5点満点）

**評価の視点：**  
シングルサイズの税込定価を基準に、提供される機能・品質・保証を総合的に勘案してコストパフォーマンスを評価する。

| 点数 | 基準 |
|------|------|
| 5.0 | 5万円未満で高機能・長期保証あり。価格以上の価値を提供 |
| 4.5 | 5〜6万円台で機能・保証が充実 |
| 4.0 | 6〜7万円台で機能・保証が充実。コスパ良好 |
| 3.5 | 7〜9万円台。品質は高いが価格もプレミアム帯 |
| 3.0 | 8万円以上でプレミアム価格帯。コスパは低め |

**各商品の採点根拠：**
- **LIMNE（リムネ）3.5点**：シングル79,900円（税込）。独自素材・10年保証・120日返金保証は価格に見合う価値があるが、純粋な価格帯としてはプレミアム。
- **雲のやすらぎプレミアム モデル3R 3.0点**：シングル79,800円（税込）。日本製・ゾーン設計・極厚23cmは評価できるが、価格帯はLIMNEと同水準でありながら保証期間の明示がやや不明瞭。
- **NELLマットレス 4.0点**：シングル67,915円〜（セール時）。ポケットコイル13層・センターハード・120日トライアル・10年保証を考慮すると、3商品中最もコスパに優れる。

### 06｜耐久性（5点満点）

**評価の視点：**  
長期使用における品質維持能力。メーカー保証期間・耐久試験データ・素材の劣化特性を総合評価。

| 点数 | 基準 |
|------|------|
| 5.0 | メーカー保証10年以上 かつ 第三者機関または公式の耐久試験データあり |
| 4.5 | 保証7〜10年または耐久試験データがいずれかのみ |
| 4.0 | 保証5〜7年。耐久性は標準的な水準 |
| 3.5 | 保証3〜5年またはへたりやすい素材特性 |
| 3.0以下 | 保証が短い、またはへたりに関する否定的な口コミが多い |

**各商品の採点根拠：**
- **LIMNE（リムネ）5.0点**：10年品質保証＋8万回耐久試験（1日20回の寝返り×10年相当）クリアを公式が明示。復元率96.5%（実力値98%）のデータあり。
- **雲のやすらぎプレミアム モデル3R 5.0点**：日本製ウレタン採用・極厚23cm設計により素材面での耐久性は高い。ただし公式サイト上での保証期間の明記が確認しにくいため、購入前に個別確認推奨。素材・構造の観点から5.0評価。
- **NELLマットレス 4.0点**：10年保証はあるが、ポケットコイルはウレタンと比較して経年でのコイルのへたり（弾力低下）が起きる可能性がある。10年保証の内容（修理・交換条件）を購入前に確認が必要。

### 07｜お試し制度（5点満点）

**評価の視点：**  
トライアル期間の長さ・返金保証の条件（全額か一部か）・返送料負担の有無。マットレスは体への馴染みに3〜4週間かかるため、最低でも60日以上が実用的な水準とする。

| 点数 | 基準 |
|------|------|
| 5.0 | 120日以上のトライアル ＋ 全額返金保証 ＋ 返送料無料 |
| 4.5 | 100〜119日のトライアル ＋ 全額返金保証 |
| 4.0 | 60〜99日のトライアル ＋ 返金保証あり |
| 3.5 | 30〜59日のトライアル |
| 3.0以下 | 30日未満またはお試し制度なし |

**各商品の採点根拠：**
- **LIMNE（リムネ）5.0点**：120日間の完全返金保証（返送料無料）。業界でも最高水準のトライアル制度。
- **雲のやすらぎプレミアム モデル3R 4.5点**：100日間の返金保証。基準を満たしており十分な期間だが、LIMNEの120日より20日短い。
- **NELLマットレス 5.0点**：120日間トライアル＋10年保証のセット。LIMNEと並んで業界最高水準。
